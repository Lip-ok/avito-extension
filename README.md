🧩 Как установить в Google Chrome

Скачать архив из гита

Открой: chrome://extensions/

Включи Developer mode

Нажми Load unpacked

Загрузи папку с расширением

## Как включить или выключить

Нажми на значок **Avito Cleaner** на панели Chrome и используй переключатель.
Настройка применяется сразу ко всем открытым вкладкам Avito.
